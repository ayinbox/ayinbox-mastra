# Security

Please report a vulnerability in this package or in the AY Inbox service by email to team@ayinbox.com. Do not open a public issue for it.

Include what you found, how to reproduce it and the version you tested. We will acknowledge the report and keep you informed while we fix it.

Never include a real API key or OAuth token in a report. If you think a credential was exposed, revoke it in the dashboard at https://app.ayinbox.com and create a new one.
